# skyscraper-puzzle-solver
Python solver for the Skyscraper puzzle using depth-first search (DFS) and backtracking with row, column, and visibility constraints.

This project is a Python implementation of a Skyscraper puzzle solver. It uses depth-first search (DFS) and backtracking to fill an 
N×N grid while enforcing uniqueness in rows and columns and satisfying visibility clues from the top, bottom, left, and right. The program reads puzzle input from standard input and outputs the completed solution grid.

How to Run -> python3 project1.py < input.txt
